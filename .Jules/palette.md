## 2025-05-15 - [Tactile & Accessible Auth]
**Learning:** Integrating haptic feedback directly into shared components (like `DmButton`) ensures a consistent "delightful" feel across the entire application with minimal code changes. Pairing this with descriptive tooltips on icon-only form toggles (like password visibility) significantly boosts both accessibility (a11y) and general usability.
**Action:** Always check core UI component libraries for opportunities to inject haptic feedback and ARIA-equivalent tooltips at the source.
